# Teaching path

1. Step `0099 + 1` to see carry pending and propagation.
2. Crank the square finite-difference preset and watch repeated addition.
3. Compare multiplication mechanisms as operation sequences.
4. Turn the Stage A hand-crank and inspect error, gradients, and weight updates.
5. Try an intentionally excessive learning rate in future presets; never confuse this counterfactual teaching machine with historical hardware.
