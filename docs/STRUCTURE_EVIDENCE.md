# 机械结构证据边界 / Structure evidence boundary

## 先说结论

本项目目前**知道计算行为，不知道每台历史机器的完整内部连接**。页面中的数字轮、进位箭头、曲柄和齿轮图示，不能被理解为某一台机器的真实剖面图。

## 四层标记

| 层级 | 含义 | 本项目如何展示 |
|---|---|---|
| **已知（A/B）** | 实物、原图、手册或可靠重建直接支持的事实 | 历史机器名称、十进制轮/计数、曲柄操作、部分已记录的功能关系 |
| **有根据的推断（C）** | 史料支持整体关系，但细节需要解释 | “进位必须影响更高位”“位架改变十进制位置”等功能性关系 |
| **教学抽象（D）** | 为了让行为可操作而画出的最小模型 | 本站的 `9→0`、`carry →`、简化齿轮、事件时间线和状态框 |
| **未知/未核实** | 当前项目没有足够证据确认 | 某台具体机器的每个齿轮、棘爪、连杆、轴、时序和实际连接路径 |

## 三个容易混淆的词

- **数字的表示**：本站核心模型只把数字表示为 `0–9` 的离散状态；历史机器可能用轮的位置、齿数、轴角或其他机械状态表示。本站没有证明某一具体历史机器的唯一表示方式。
- **进位**：本站证明的是功能行为：个位从 `9` 回到 `0` 时，更高位需要增加 `1`。页面画的箭头是“功能关系”，不是已确认的连杆路线。
- **连接**：`A → B` 在本站默认表示“状态/信息影响”，除非有明确来源，否则不表示两件实体零件直接啮合或相连。

## 页面阅读规则

看到结构图时先看右上角证据徽章：

1. **功能层**：我们知道它必须实现什么；
2. **证据层**：我们知道哪些来自史料；
3. **教学层**：我们为了演示暂时画了什么；
4. **未知层**：不要从简图推断真实内部结构。

本项目宁可显示一个标为“未知”的空白区域，也不把猜测画成剖面。后续若加入具体机器结构，必须附来源、图号/页码或重建依据，并单独标注证据等级。
